# core ロジックの TDD 記録

仕様の元: `docs/設計.md`。テストは `tests/`、実行は `pwsh -NoProfile -File tests/run.ps1` (MSVC, `/W4 /WX`)。
各モジュールで「失敗するテストを先に入れて RED を確かめてコミット → 実装して GREEN を確かめてコミット」を守る。

## 利用者の流れ (設計から)

- 物品の QR を読ませ、最後に名札の QR を読ませて持出・返却を確定する
- 貸出中の一覧で、物品番号・借りた人・持出からの経過 (「N分前」「N時間前」) を見る
- 引き出しを開けて QR を読ませないと、40 秒・60 秒で警告が鳴る

## カバレッジと既知の穴

- **カバレッジは測れていない。** MSVC の Community 版にはコードカバレッジが無く、OpenCppCoverage 等も入っていない。
  代わりに、各モジュールの境界値 (長さ 1/2/15/16、59/60 分、日付跨ぎ、millis の一周) をテストに列挙している
- `csv_export`: 先頭が = + - @ の値は Excel で数式として解釈されうるが、物品番号を書き換えないため手を入れていない
- core は ESP32 側の gcc でもビルドするが、ホストの MSVC でしか実行していない。実機では統合ファーム (M5) でシリアル越しに確かめる
